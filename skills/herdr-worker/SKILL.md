# herdr-worker

Your dispatch pointer named your run, assignment, and profile. Read, in this order:

1. `references/role.md` — who you are, where the run lives, and how to resolve the assignment
2. `mcp://herdr://contract` — the common contract: §Authority, §Reserved to the user, §Assignment and settlement grammar
3. `references/profile-<profile>.md` — the profile named in your dispatch pointer

Afterwards, read the reference for the boundary you are at:

| At | Read |
|---|---|
| Recording evidence or writing your lane report | `references/report.md` |
| Editing in the shared project working directory | `references/worktree.md` |
| Missing or conflicting judgment | `references/judgment.md` |
| Writing or reading a peer channel | `references/peers.md` |
| Reporting completion, failure, or a blocked boundary | `references/completion.md` |
| Always | `references/prohibitions.md` |
